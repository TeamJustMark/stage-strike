# F&F Stage Strike

A pass-the-phone stage striker for Smash Ultimate HewDraw Remix sets at Flashbacks & Friendlies 2026.

- Game 1: coin flip or RPS, then 1-2-1 strikes on the starters.
- Game 2 and on: the winner strikes, the loser picks. DSR, modified DSR or no-repeat clause.
- Best of 3 or 5, score and game history, undo and reset.
- Four looks: Banner, Tennis, Grilled, Cannery.
- Settings and the set in progress are saved on the phone (localStorage).

One static `index.html` with no build step. Stage pictures and names come from HewDraw Remix's stage select.
